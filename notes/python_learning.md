# Заметки по Python

## Чтение файлов

Используется в функции [get_content](../rag/ingestion/loader.py).

`Path.read_text(encoding="utf-8")` читает весь текст и закрывает файл.
Эквивалентный вариант с явным управлением открытым файлом:

```python
with path.open("r", encoding="utf-8") as file:
    return file.read()
```

При `return` Python сначала вычисляет возвращаемое значение, затем выходит
из `with`, закрывает файл и возвращает результат.

Для обработки большого файла по строкам можно использовать:

```python
with path.open("r", encoding="utf-8") as file:
    for line in file:
        process_line(line)
```

Здесь `process_line` — условное имя функции обработки, которую нужно определить.
Так не требуется читать весь файл в одну строку.

## Сборка контекста

Используется в функции [build_context](../llm/prompt_builder.py).

Первоначальный вариант через индексы и наращивание строки:

```python
def build_context(chunks):
    result = ""
    for index in range(len(chunks)):
        result += f"[{index + 1}] {chunks[index][0]}\n"
    return result
```

Этот вариант работает, но оставляет перенос строки после последнего фрагмента.
В текущей реализации `enumerate` задаёт номера, распаковка пары позволяет
получить текст без обращения по индексам, а `"\n".join(lines)` соединяет
строки с переносами только между ними.

Для небольшого числа чанков разница в скорости несущественна. Для большого
числа строк сборка списка с последующим `join` обычно предпочтительнее
многократного наращивания строки через `+=`.
